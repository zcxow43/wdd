# Currency Pair API (Brand-Scoped)

此 API 負責單一品牌對某個幣種對的個別設定，包括匯率方式（自動或手動）、匯率值、精度限制與啟用狀態的查詢、建立、修改與刪除。多數資料是在建立幣種對定義時自動產生，但此 API 也允許單獨新增或刪除某一筆品牌幣種對（例如補建一筆先前被刪除的資料）。查詢一律讀取目前生效資料；所有異動皆直接套用到正式資料，不需送審核准。手動匯率的數值與小數位數會依其所屬幣種對定義的精度設定進行檢核。

## 欄位定義
| Field | Type/Role | Rule |
|---|---|---|
| id | 識別碼 | 主鍵 |
| currencyPairDefinitionId | 關聯欄位 | 建立時必填，須對應現有幣種對定義；建立後不可變更 |
| baseCurrencyCode / quoteCurrencyCode | 顯示欄位 | 唯讀，透過所屬定義帶出 |
| brandId | 關聯欄位 | 建立時必填，須對應現有品牌；建立後不可變更 |
| brandCode | 顯示欄位 | 唯讀，由品牌帶出 |
| rateType | 匯率方式 | `AUTO`（自動）或 `MANUAL`（手動）；未指定時預設為自動 |
| rate | 匯率值 | 手動匯率時必填且須大於 0，小數位數不得超過所屬定義的精度設定；自動匯率時一律清空為空值，即使有帶值也不採用 |
| active | 啟用狀態 | 預設為停用；可自由開啟或關閉 |
| createdAt / updatedAt | 系統時間 | 系統自動維護 |

## 限制條件
- 所屬幣種對定義與所屬品牌一旦建立即不可變更。
- 「所屬定義＋品牌」組合須唯一，重複建立會被拒絕。
- 手動匯率時，匯率值必填、必須大於 0，且小數位數不得超過所屬定義的精度上限；改為自動匯率時，匯率值一律清空。
- 啟用狀態可任意開啟或關閉，無額外前提條件。
- 刪除品牌幣種對沒有任何前提限制，不論目前是否啟用皆可直接刪除。

## 跨主題規則
- 手動匯率的小數位數上限，取決於其所屬幣種對定義目前設定的精度值，而非此資料自身設定（見 currency-pair-definition.md）。
- 本資料的啟用/停用狀態，是幣種對定義能否被刪除的判斷依據之一；只要仍有啟用中的品牌幣種對，其所屬定義即無法刪除（見 currency-pair-definition.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/currency-pairs | 查詢品牌幣種對清單，可依定義、品牌、啟用狀態篩選 | Live direct |
| GET | /api/currency-pairs/{id} | 查詢單一品牌幣種對 | Live direct |
| POST | /api/currency-pairs | 為某品牌新增一筆幣種對設定 | Direct |
| PUT | /api/currency-pairs/{id} | 調整品牌幣種對的匯率方式、匯率值或啟用狀態 | Direct |
| DELETE | /api/currency-pairs/{id} | 刪除單一品牌幣種對 | Direct |
