# Brand API

品牌主檔 API 提供七個系統內建品牌（au、moneta、pug、star、um、vjp、vt）的查詢與啟用/停用管理，是匯率中心所有品牌相關設定的歸屬根源。品牌只能透過系統預先建立，沒有新增或刪除的入口，代碼與名稱一律不可修改；唯一能透過 API 異動的欄位是啟用狀態。查詢一律讀取目前生效資料，而啟用/停用的異動會直接套用並立即生效，不需要送審核准。

## 欄位定義

**Brand**

| Field | Type/Role | Rule |
|---|---|---|
| id | 識別碼 | 系統產生的唯一識別碼 |
| code | 品牌代碼 | 系統預先建立，不可修改 |
| name | 品牌名稱 | 系統預先建立，不可修改 |
| active | 啟用狀態 | 唯一可透過 API 異動的欄位 |
| createdAt / updatedAt | 時間戳記 | 系統自動維護 |

## 限制條件
- 品牌僅有系統預先建立的七個，沒有任何 API 可以新增品牌。
- 沒有任何 API 可以刪除品牌。
- 品牌代碼與名稱一律不可修改，僅能異動啟用狀態。
- 異動請求若未提供啟用狀態，視為無效請求並拒絕（400）。
- 查詢或異動指定品牌時，若該品牌不存在，回覆找不到資料（404）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/brands | 查詢品牌清單，可依啟用狀態篩選 | No API（查詢，非異動） |
| GET | /api/brands/{id} | 查詢單一品牌詳細資料 | No API（查詢，非異動） |
| PUT | /api/brands/{id} | 切換品牌的啟用/停用狀態 | Direct（直接套用，免送審） |
