# Brand API

此規格提供品牌的查詢與啟用/停用功能。品牌是一組固定的種子資料，本身沒有新增或刪除的功能，只能查詢清單、查詢單一品牌，以及切換其啟用狀態。啟用狀態的變更會直接套用，不需要經過審核流程。品牌的代碼與名稱一旦建立即不可修改，唯一可以透過 API 變更的欄位就是啟用狀態。

## 欄位定義
| Field | Type/Role | Rule |
|---|---|---|
| id | 識別碼 | 系統自動產生 |
| code | 品牌代碼 | 建立後不可變更，僅由資料庫種子資料建立 |
| name | 品牌名稱 | 建立後不可變更，僅由資料庫種子資料建立 |
| active | 啟用狀態 | 必填布林值，唯一可透過 API 修改的欄位 |
| createdAt / updatedAt | 建立/更新時間 | 系統自動記錄 |

## 限制條件
- code、name 為不可變更欄位，僅能透過資料庫種子資料建立，無法透過 API 新增或修改
- 沒有新增品牌或刪除品牌的 API，品牌集合固定（AU、MONETA、PUG、STAR、UM、VJP、VT）
- active 為唯一可透過 API 修改的欄位，且變更直接套用，不經審核

## 跨主題規則
- 每個幣種對都必須歸屬於一個既有品牌，品牌是幣種對的擁有者（見 currency-pair.md）

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/brands | 查詢品牌列表，可依啟用狀態篩選 | Live direct |
| GET | /api/brands/{id} | 查詢單一品牌 | Live direct |
| PUT | /api/brands/{id} | 切換品牌啟用/停用狀態 | Direct |
