# Exchange Rate Sync（匯率同步） API

這支 API 負責向外部市場匯率來源取得最新匯率，並針對每個幣種對定義、對每個品牌各存一筆快照，內容包含原始匯率，以及在同步當下依該品牌那時的生效點差百分比即時算出的入金/出金匯率；點差同樣是以乘法套用的百分比（原始匯率 ×（1 + 點差百分比 / 100）），不是固定金額相加，而且一旦寫入就是歷史快照，之後點差再調整也不會回頭改寫已同步的紀錄。為避免過度呼叫外部來源，任兩次成功同步之間至少要間隔 60 秒。這是一支系統性的市場資料更新作業，不是品牌設定變更，因此不經過審核流程，呼叫後立即直接寫入資料。

## 欄位定義

**ExchangeRate**
| Field | Type/Role | Rule |
|---|---|---|
| id | 識別鍵 | 系統產生 |
| currencyPairDefinitionId | 所屬幣種對定義 | 對應一筆幣種對定義 |
| baseCurrencyCode / quoteCurrencyCode | 顯示欄位 | 由定義帶出 |
| brandId | 所屬品牌 | 對應一筆品牌 |
| brandCode | 顯示欄位 | 由品牌帶出 |
| rate | 原始匯率 | 外部來源回傳的原始值，不含任何點差調整；同一定義、同一分鐘下，各品牌此值皆相同 |
| depositRate | 入金匯率快照 | 原始匯率乘上「(1 + 該品牌當下生效入金點差百分比 / 100)」，於同步當下算出並凍結存檔，之後不會重算 |
| withdrawalRate | 出金匯率快照 | 計算方式同上，改用當下生效出金點差百分比，同樣凍結存檔 |
| rateMinute | 同步時間（精確到分鐘） | 同一次同步作業下所有列共用同一個時間值 |
| source | 資料來源標示 | 例如外部匯率提供者名稱 |
| createdAt / updatedAt | 系統時間戳 | 系統自動維護 |

## 限制條件

- 同一組（幣種對定義, 品牌, 同步分鐘）只會存在一筆資料，同分鐘內重複同步會更新既有列而不是新增
- `rate` 完全依外部來源原樣儲存，不會依定義的精度做四捨五入
- `depositRate`/`withdrawalRate` 只在同步當下計算一次並存成快照，之後即使品牌點差設定改變，既有紀錄也不會被回頭更新，只有下一次同步才會產生反映新設定的新紀錄
- 任兩次「成功」同步之間至少須間隔 60 秒，且此限制是全域性的（涵蓋所有定義與所有品牌），不是逐品牌計算；同步失敗（外部來源全部呼叫失敗）不會啟動或延長這個間隔限制
- 本 API 兩支端點皆不經過審核流程，永遠是查詢或直接寫入

## 跨主題規則

- 每筆快照的入金/出金匯率，是以與 currency-pair.md 即時計算「入金/出金加點完成匯率」相同的生效點差解析規則（群組優先、否則品牌預設）算出，差別只在於這裡是同步當下凍結的一次性結果，而不是每次查詢都重新計算（見 currency-pair.md、spread.md）。
- 當品牌幣種對的匯率類型為自動（AUTO）時，其目前生效的基礎匯率取自本 API 最近一次同步存下的原始匯率（見 currency-pair.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/exchange-rates/latest | 查詢每個（幣種對定義, 品牌）組合最近一次同步的匯率快照（可依品牌篩選） | Live direct |
| POST | /api/exchange-rates/sync | 觸發一次同步作業，向外部來源取得最新匯率並為每個品牌寫入快照 | Direct |
