# Currency API

此 API 提供幣種主檔的完整維護能力，包含查詢、新增、修改與刪除。查詢一律讀取目前生效資料。所有異動（新增、修改、刪除）皆為直接套用，送出即立即生效，不需送審核准。幣種代碼一經建立後即不可變更，其他欄位（名稱、符號、小數位數）在建立後仍可修改。

## 欄位定義

**Currency**

| Field | Type/Role | Rule |
|---|---|---|
| id | 識別碼 | 系統產生的唯一編號 |
| code | 幣種代碼 | 建立時必填；須為 3 個大寫英文字母；全系統唯一；建立後不可變更 |
| name | 幣種名稱 | 必填；可修改 |
| symbol | 幣種符號 | 必填；可修改 |
| decimalPlaces | 小數位數 | 必填；範圍 0 至 8；可修改 |
| createdAt / updatedAt | 建立/更新時間 | 系統自動維護 |

## 限制條件

- 幣種代碼建立後永久不可變更，即使修改請求中帶有不同代碼也會被忽略。
- 幣種代碼須符合 3 個大寫英文字母格式，且全系統不可重複；重複時拒絕新增（409）。
- 新增與修改時，名稱、符號為必填非空白，小數位數須為 0 至 8 之間的整數；違反時拒絕並說明原因（400）。
- 查詢或修改指定不存在的幣種時，回報查無資料（404）。
- 刪除幣種為直接刪除，成功後資料即從主檔移除，不經任何審核流程。

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/currencies | 查詢所有幣種清單 | Direct |
| GET | /api/currencies/{id} | 查詢單一幣種明細 | Direct |
| POST | /api/currencies | 新增一筆幣種 | Direct |
| PUT | /api/currencies/{id} | 修改幣種名稱、符號、小數位數（代碼不可改） | Direct |
| DELETE | /api/currencies/{id} | 刪除一筆幣種 | Direct |
